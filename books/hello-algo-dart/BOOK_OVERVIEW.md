# BOOK_OVERVIEW — 《Hello 算法》Dart 版

## 主旨

一本面向算法初学者的**图解式数据结构与算法入门书**，以动画图解 + 可运行代码 + 生活类比的方式，帮助读者建立数据结构与算法的知识体系。本书强调动手实践，所有代码均在 GitHub 上一键运行，适合准备技术面试和系统学习算法的读者。

## 知识骨架

### 三段式学习路线

本书隐含的三阶段学习路径：

1. **阶段一：算法入门**（第 1-3 章）— 算法概念、复杂度分析、数据结构基础
2. **阶段二：数据结构通识**（第 4-9 章）— 数组/链表、栈/队列、哈希表、树、堆、图
3. **阶段三：算法进阶**（第 10-15 章）— 搜索、排序、分治、回溯、动态规划、贪心

### 章节逻辑脉络

```
前言（学习路径指引）
  └─ 初识算法（算法无处不在、什么是算法）
       └─ 复杂度分析（时间/空间复杂度、迭代与递归）
            └─ 数据结构分类
                 ├─ 基础数据结构（数组、链表、栈、队列、哈希表）
                 ├─ 树形结构（二叉树、二叉搜索树、AVL 树、堆）
                 └─ 图结构（图遍历、图算法）
                      └─ 核心算法策略
                           ├─ 搜索（二分查找）
                           ├─ 排序（选择、冒泡、插入、快速、归并、堆排序等）
                           ├─ 分治（构建归并排序、汉诺塔）
                           ├─ 回溯（全排列、子集和、N 皇后）
                           ├─ 动态规划（背包、编辑距离、爬楼梯）
                           └─ 贪心（零钱兑换、分数背包、最大容量）
```

## 关键术语

| 术语 | 书中解释 |
|------|----------|
| 时间复杂度 | 衡量算法运行时间随数据量增长的趋势，用大 O 表示法 |
| 空间复杂度 | 衡量算法运行时的内存占用随数据量增长的趋势 |
| 递归 | 函数调用自身，分为递（向下深入）和归（向上回溯）两个阶段 |
| 回溯 | 遍历所有可能解的搜索方法，遇错则回退、尝试其他路径 |
| 动态规划 | 将问题分解为子问题，通过存储子问题解避免重复计算（"从底至顶"） |
| 分治 | 将问题分解为独立子问题，递归求解后合并结果 |
| 贪心 | 每一步都选择当前最优解，期望最终达到全局最优 |
| 哈希冲突 | 不同 key 映射到同一桶的现象，用链式地址或开放寻址解决 |
| 平衡二叉树 | 任意节点左右子树高度差不超过 1 的二叉树（AVL 树） |

## 批判性分析

### 本书优势
- **视觉化教学**：每个算法都配有动画图解和流程图，非常直观
- **代码一键运行**：所有示例代码附带测试用例，可动手验证
- **生活类比**：用扑克牌、拼装积木等日常场景解释抽象概念，降低入门门槛
- **学习路径清晰**：明确了三阶段学习路线，避免读者迷失

### 局限性
- **深度有限**：覆盖的是经典基础内容，高级算法（如字符串匹配、数论、计算几何）不在范围内
- **Dart 语言特性利用不充分**：代码以算法逻辑为主，较少展示 Dart 特有的语言能力（如扩展方法、集合操作符链、Record 模式匹配）
- **缺少算法复杂度证明**：给出了复杂度结论，但没有严格的数学推导证明
- **面试导向但缺实战题目**：虽以面试准备为目标，但每章后缺少配套练习题目
- **代码风格不一**：部分代码使用了 C/Java 风格，未完全遵循 Effective Dart 惯例

### 与学习路线的互补
- 本书适合作为 **dart-fundamentals** 和 **dart-core-libraries** 的实践配套
- 基础数据结构部分可配合 **dart-classes-objects** 理解类的设计
- 动态规划/回溯部分可配合 **dart-collections-iterables** 练习数据变换
- 如果想学习 Dart 语言特有技巧，仍需结合官方文档和其他 Dart 专项书籍
